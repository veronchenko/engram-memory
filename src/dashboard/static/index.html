Entry types

hub
One per project — what it is, its stack, its connections.
feature
A notable feature and how it's built.
decision
A choice made among alternatives, without a standalone artifact.
pattern
A reusable approach that originated in one project.
integration
A client or adapter built for an external system.
diagnostic
The root cause and fix of a resolved bug or incident.
procedure
Steps for a non-obvious one-off task.
preference
A dev or tooling preference, not tied to one project.
snippet
A small reusable code or config example.

Graph controls

  • Drag a node to reposition it.
  • Scroll to zoom, drag empty space to pan.
  • Click a node to open its entry.
  • Click a legend chip to filter by type — matches stay lit, others dim rather than disappear.

Search

  • Results are ranked by relevance, fusing keyword and semantic (meaning-based) match.

Click a node to view or edit its entry, or start a new one.
